# Digital Personal Space – Damar Putera Koerdi

Ruang digital kecil untuk menyimpan pikiran, teknologi, kenangan, dan percakapan yang mungkin suatu hari ingin diingat kembali.

Personal portfolio & reflective digital garden yang dibangun dengan HTML, Tailwind CSS, dan JavaScript vanilla (hybrid multi-page feel dengan dynamic load).

## Fitur Utama

- **Single Portal (index.html)** → Hero + grid cards ke semua section
- **Dynamic Loading** → Klik card → load konten dari file terpisah tanpa reload full page
- **Dark Mode Support** → Auto via Tailwind `dark:` classes
- **Responsive & Mobile-Friendly** → Grid flex, Tailwind breakpoints
- **Section Unik**:
  - Tentang Saya (refleksi diri)
  - Portofolio (highlight project)
  - Ruang Teknologi (eksplorasi web/AI/UI)
  - Ruang Kenangan (momen personal)
  - Journal (pikiran harian)
  - Blog (tulisan mendalam)
  - Quotes (inspirasi acak + favorit)
  - AI Teman Diskusi (chat prototype placeholder)
  - Hubungi Saya (form kontak via Formspree)

## Teknologi yang Digunakan

- HTML5 + CSS (Tailwind CSS via CDN)
- JavaScript vanilla (fetch untuk hybrid load, localStorage untuk quotes favorit)
- GitHub Pages (hosting gratis)
- Font: Inter (Google Fonts)
